# 0x09. C - Static Libraries

## Description
This project covers the creation and use of static libraries in C.

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with all function prototypes |
| `libmy.a` | Static library containing all functions |
| `create_static_lib.sh` | Script to create a static library from all .c files |
