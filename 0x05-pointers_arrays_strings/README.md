# 0x05. C - Pointers, Arrays and Strings

This project covers the basics of pointers, arrays, and strings in C.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Compilation: `Ubuntu 20.04 LTS` using `gcc` with `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Code style: Betty Style
- No global variables
- No more than 5 functions per file
- Standard library functions like `printf`, `puts` are forbidden. Use `_putchar`.
