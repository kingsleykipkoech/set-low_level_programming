# 0x03-debugging

This project covers techniques on how to debug C programs, including reading error messages and manual debugging.

## Tasks

* **0. Multiple Mains**: Test that `positive_or_negative()` gives the correct output for 0.
* **1. Like, Comment, Subscribe**: Comment out an infinite loop.
* **2. 0 > 972?**: Fix `largest_number()` function correctly determine the largest of three numbers.
* **3. Leap Year**: Fix `print_remaining_days()` function correctly account for leap years.
