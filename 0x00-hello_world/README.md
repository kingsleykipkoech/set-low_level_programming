# C - Hello, World

This project is part of a low-level programming curriculum. It covers the basics of the C programming language, including the compilation process, basic I/O using `puts` and `printf`, and data types.

## Files
- `0-preprocessor`: Script that runs a C file through the preprocessor and saves the result in `c`.
- `1-compiler`: Script that compiles a C file but does not link (outputs a `.o` file).
- `2-assembler`: Script that generates the assembly code of a C code.
- `3-name`: Script that compiles a C file and creates an executable named `cisfun`.
- `4-puts.c`: C program that prints a specific string using `puts`.
- `5-printf.c`: C program that prints a specific string using `printf`.
- `6-size.c`: C program that prints the size of various types.
