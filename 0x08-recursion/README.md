# 0x08. C - Recursion

## Description
This project explores recursion in C programming. Each function is implemented
using recursive calls only — no loops or static variables are used.

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with all function prototypes |
| `0-puts_recursion.c` | Prints a string followed by a new line |
| `1-print_rev_recursion.c` | Prints a string in reverse |
| `2-strlen_recursion.c` | Returns the length of a string |
| `3-factorial.c` | Returns the factorial of a given number |
| `4-pow_recursion.c` | Returns x raised to the power of y |
| `5-sqrt_recursion.c` | Returns the natural square root of a number |
| `6-is_prime_number.c` | Returns 1 if a number is prime, 0 otherwise |

## Compilation
```bash
gcc -Wall -pedantic -Werror -Wextra -std=gnu89 <source files> -o <output>
```
