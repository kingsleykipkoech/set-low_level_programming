# AI: Pre-processor Co-pilot

## Scenario Choice
Scenario A: Creating a simple arithmetic macro `MULTIPLY(a, b)`.

## Task Overview
This task demonstrates using AI as a Co-pilot to correctly manage C Preprocessor macros, identifying safety issues like operator precedence, and generating robust conditional compilation scaffolds.

## Files
- `initial_macro.c`: The unsafe version of the macro missing parentheses, leading to precedence errors.
- `refactored_macro.c`: The safe version of the macro with proper parentheses and conditional compilation for debugging.
