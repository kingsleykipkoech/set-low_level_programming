# 0x0B. C - Preprocessor

This module explores the C preprocessor, macros, and include guards.

## Files
* `0-object_like_macro.h`: Macro `SIZE` defined as `1024`.
* `1-pi.h`: Macro `PI` defined as `3.14159265359`.
* `2-main.c`: Program that prints the name of the file it was compiled from.
* `3-function_like_macro.h`: Macro `ABS(x)` that computes the absolute value of `x`.
* `4-sum.h`: Macro `SUM(x, y)` that computes the sum of `x` and `y`.
