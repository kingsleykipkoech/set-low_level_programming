# 0x01. C - Variables, if, else, while

This project covers:
- Arithmetic operators in C
- Relational and logical operators
- `if`, `if ... else` statements
- `while` loops
- `putchar` function
- Base 10 and Base 16

## Files
- `0-positive_or_negative.c`: Positive or negative number check.
- `1-last_digit.c`: Print last digit and its properties.
- `2-print_alphabet.c`: Print the alphabet in lowercase.
- `3-print_alphabets.c`: Print lowercase then uppercase alphabet.
- `4-print_alphabt.c`: Print alphabet excluding 'q' and 'e'.
- `5-print_numbers.c`: Print single digit numbers.
- `6-print_numberz.c`: Print numbers using `putchar` without `char`.
- `7-print_tebahpla.c`: Print alphabet in reverse.
- `8-print_base16.c`: Print base 16 numbers.
- `9-print_comb.c`: Print combinations of single-digit numbers.
